# Suspecto

An offline pass-the-phone party word game built with Flutter. No .NET API,
accounts or remote database are required for this milestone.

## Playable milestone

- 3–20 named players, 1–3 imposters (strictly fewer than half the group)
- Local category selection and 1/3/5-minute discussion timer
- Hold-to-reveal private roles; release or background the app to hide
- Private voting, no self-votes, tie handling and results
- Multiple-imposter rules: accuse the top N suspects; catch all imposters to win
- Rematch with the same players and settings or return to setup
- Scrollable layouts for shorter displays

Words are bundled starter content. Downloads, persistent history, purchases,
localization and online multiplayer are later milestones.

## Run locally

Install the current stable Flutter SDK, then:

```bash
flutter pub get
flutter create --empty --platforms=android,ios,web --project-name suspecto --org com.suspecto .
flutter analyze
flutter test
flutter run
```

Platform runner folders are generated by Flutter; they are not yet committed.
The `com.suspecto` application ID is a development placeholder to finalize before
store publication. No store-ready APK/IPA or signing configuration is included.

CI runs analysis, domain/widget tests and a web build smoke test. See
`docs/architecture.md` for the offline-first/backend direction.
